# AI Slop & UI/UX Anti-Patterns Catalog

This catalog documents the recurring pathologies generated by Large Language Models when generating frontend applications, along with their high-performance B2B replacements.

---

## 1. Visual Aesthetics & Styling Anti-Patterns

| AI Slop Anti-Pattern | Operational Defect | CraftUI B2B Correction |
| :--- | :--- | :--- |
| **Glowing/Neon Shadows** (`shadow-[0_0_30px_rgba(...)]`) | Causes visual fatigue, looks like a video game or crypto landing page rather than accounting software. | Remove ambient glows. Use single-pixel subtle borders (`border-slate-800` or `border-gray-200`) and slight elevation shadows only on modals. |
| **Rainbow Badges & Tags** | Every tag has a different saturated color (purple, pink, emerald, cyan, amber), turning lists into carnival noise. | Limit palette to 3 functional states: **Neutral** (inactive/general), **Success** (paid/in-stock), and **Danger/Alert** (debt/out-of-stock). |
| **Excessive Border Radius** (`rounded-3xl` on cards & tables) | Wastes valuable corner pixels and looks juvenile for enterprise workflows. | Standardize on `rounded-lg` (8px) for buttons/cards and `rounded-md` (6px) for inputs. |
| **Sprawling Card Grids for Large Datasets** | Displaying 50 items as gigantic cards requires endless scrolling and hides comparisons. | Convert to high-density tabular views (`<table>`) with monospaced numbers, compact padding (`py-2 px-3`), and hover state highlights. |

## 2. Copy, Typography & Content Bloat

| AI Slop Anti-Pattern | Operational Defect | CraftUI B2B Correction |
| :--- | :--- | :--- |
| **Chatty Marketing Greeting Copy** | *"مرحباً بك في لوحة تحكم المنظومة الذكية الرائدة لمراقبة المخازن"* takes up 120px of precious vertical viewport. | Short, declarative titles: *"المخزون والمستودع"*. Subtitles omitted or reduced to breadcrumb counters (e.g. *"148 محرك متاح"*). |
| **Redundant Form Instructions** | *"يرجى إدخال رقم المحرك التسلسلي بدقة لضمان تسجيل الفاتورة في النظام بشكل سليم"* under an input titled *"رقم المحرك"*. | Eliminate helper text. Use short placeholder: `مثال: 2TR-FE-8921`. |
| **Fake AI Pre-filled Defaults** | Pre-populating form inputs with fictitious values ("جون دو", "شركة الأمل لقطع الغيار") that operators must backspace out. | Inputs must start empty or intelligently autofocus with default focus on the first input. |
| **Dramatic Dialog Confirmations** | Asking 3 confirmation prompts for standard operations or showing celebratory confetti on ordinary sales. | Non-destructive actions complete instantly with a quiet toast; confirmations reserved only for critical irreversible operations (e.g. database wipe). |

## 3. Workflow & Input Friction

| AI Slop Anti-Pattern | Operational Defect | CraftUI B2B Correction |
| :--- | :--- | :--- |
| **Monolithic 15-Field Forms** | Forcing an operator to scroll through 15 required inputs just to add an incoming item. | **The 4-Vital-Field Rule**: Keep the top 4 fields visible (Identifier, Name/Model, Cost, Price). Group specs, warranties, and docs into a collapsible progressive disclosure accordion. |
| **Multi-Click POS Checkout** | Selecting payment -> entering amount -> confirming change -> clicking finalize (4-6 clicks per customer). | **1-Click Cash Checkout**: A dedicated "كاش فوري" button that calculates exact amount, settles the invoice, logs to treasury, and triggers print in 1 action. |
| **Mouse-Only Dependency** | Modals and lists that cannot be navigated, submitted, or cancelled via keyboard. | Bind `Enter` to submit, `Escape` to close modals, numeric keypad typing for PIN/amounts, and automatic focus (`autoFocus`) on search inputs. |

## 4. Hardware & Data Architectural Neglect

| AI Slop Anti-Pattern | Operational Defect | CraftUI B2B Correction |
| :--- | :--- | :--- |
| **Reckless Cloud Storage of Binaries** | Uploading 5MB high-res camera pictures of customs clearance papers directly into Firestore/JSON documents, hitting quota limits. | Store heavy images **100% locally** in client-side IndexedDB. Sync only lightweight relational metadata to cloud DBs. |
| **Disregard for POS Thermal Printers** | Providing only A4 standard PDF prints that print tiny, unreadable, cut-off text on 80mm roll printers. | Implement dedicated `@media print` CSS for 80mm continuous rolls with black & white thermal typography, dashes, and bold barcodes. |
| **Corrupted Excel Exports** | Exporting UTF-8 Arabic text to CSV without a Byte Order Mark, turning Arabic characters into unreadable symbols (`Ø§Ù„Ù…Ø­Ø±Ùƒ`). | Always prepend `\uFEFF` (UTF-8 BOM) to the generated CSV Blob string. |
